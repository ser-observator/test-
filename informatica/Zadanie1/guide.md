# Гайд: ЕГЭ Информатика, Задание 1

Задание 1 проверяет умение определять кратчайшее расстояние между пунктами в графе или количество путей.

## Основные алгоритмы решения

1. **Метод взвешивания (для поиска кратчайшего пути):**
   - Присвойте начальному пункту значение 0.
   - Последовательно вычисляйте минимальное расстояние до каждого следующего пункта, опираясь на уже известные значения предыдущих.
   - Используйте формулу: `Путь(Б) = min(Путь(А) + Расстояние(А, Б))` для всех входящих в Б пунктов А.

2. **Метод подсчета (для поиска количества путей):**
   - Присвойте начальному пункту значение 1.
   - Для каждого следующего пункта суммируйте значения всех входящих в него пунктов.
   - `Кол-во(Б) = сумма(Кол-во(А))` для всех входящих в Б пунктов А.

## Полезные советы
- **Внимательность:** Читайте условие (часто есть ограничение: "обязательно проходит через город X").
- **Проверка:** Всегда пересчитывайте путь в обратном направлении, если есть сомнения.
- **Таблица:** Если граф сложный, рисуйте таблицу переходов, чтобы ничего не пропустить.

## Алгоритм действий
1. Нарисуйте граф, если его нет в явном виде.
2. Отметьте начальный и конечный пункты.
3. Пронумеруйте вершины по порядку их "удаленности" от начала.
4. Выполните вычисления (сумма или минимум).
