Шпаргалка Turtle для ЕГЭ (Задача №6)

1. Базовая настройка
   from turtle import *
   tracer(0)      # Отключить анимацию (мгновенное рисование)
   speed(0)       # Максимальная скорость
   
2. Движение
   fd(n)          # Вперед на n пикселей
   bk(n)          # Назад на n пикселей
   rt(a)          # Поворот направо на a градусов
   lt(a)          # Поворот налево на a градусов

3. Управление пером
   pu()           # Поднять перо (не рисует)
   pd()           # Опустить перо (рисует)
   goto(x, y)     # Перейти в точку с координатами (x, y)

4. Полезные приемы
   - Масштабирование: Используй переменную k (например, k=20), чтобы рисунок был крупнее:
     fd(5 * k)
   - Циклы:
     for _ in range(N):
         # Команды
   - Сетка для подсчета точек:
     # Чтобы нарисовать точки для подсчета, используй вложенный цикл:
     for x in range(-20, 20):
         for y in range(-20, 20):
             pu()
             setpos(x * k, y * k)
             pd()
             dot(5, 'red')  # Рисует красную точку размером 5
             
   - Завершение программы:
     update()       # Обязательно вызвать, если был tracer(0)
     exitonclick()  # Окно закроется при клике
